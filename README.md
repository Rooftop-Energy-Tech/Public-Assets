# Public Assets

Branding images, icons, and other public assets for the RooftopIQ platform.

## assetIQ logos

assetIQ brings together gensetIQ, solarIQ and telcoIQ. Each product has four variants, as SVG in `assetIQ/svg/` and as transparent PNG in `assetIQ/png/`:

| File | Look | Use on |
| --- | --- | --- |
| `<product>-logo-white` | Word in colour, white IQ | Dark backgrounds |
| `<product>-logo-black` | Black word, IQ in colour | Light backgrounds |
| `<product>-icon-white` | White IQ, tail in colour | Dark backgrounds |
| `<product>-icon-black` | Black IQ, tail in colour | Light backgrounds |

Colours: gensetIQ `#21B0B0`, solarIQ `#3FF39F`, telcoIQ `#0061F7`. The PNGs are rendered at 4x from the SVGs: 744 px tall for the logos and 680 px for the icons.
