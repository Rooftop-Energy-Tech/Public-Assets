# Public Assets

Branding images, icons, and other public assets for the RooftopIQ platform.

## assetIQ logos

The assetIQ logo and icon, as SVG in `assetIQ/svg/` and as transparent PNG in `assetIQ/png/`:

| File | Look | Use on |
| --- | --- | --- |
| `assetIQ Logo - Dark Mode` | Blue word, white IQ | Dark backgrounds |
| `assetIQ Logo - Light Mode` | Black word, blue IQ | Light backgrounds |
| `assetIQ-icon-white` | White IQ, blue tail | Dark backgrounds |
| `assetIQ-icon-black` | Black IQ, blue tail | Light backgrounds |

Colour: `#0061F7`. The logo PNGs are 645 × 170 px and the icon PNGs are 912 × 680 px.
